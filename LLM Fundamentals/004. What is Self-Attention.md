So far, we have understood what tokens are and what is a context window. But, how does an LLM understand the relationship between the tokens in a sequence?

Self-attention is the technique that the LLM uses to decide which other words or tokens matter when interpreting the current token.

Think of a sentence:

    “The animal didn’t cross the street because it was too tired.”

When the model reads “it,” self-attention helps it connect “it” to “animal,” not “street.”

The model does this by comparing each token with every other token and assigning attention weights: higher weight means “this token is more relevant right now.”

Before 'Transformers,' models processed text sequentially word by word. They had limited ability to capture long-range dependencies.

Self-attention solves this by processing all the tokens in parallel and allowing direct connections between any two tokens, regardless of the distance.

In Transformer LLM, each token is turned into three learned vectors -

    1. Query -> What this token is looking for
    2. Key -> What this token offers for matching
    3. Value -> The information this token can pass along

For each token, the model compares its 'Query' with other tokens’ 'Keys'. The better the match, the more attention that token receives. Then the model blends the corresponding 'Values' together to create a context-aware representation.

So instead of reading text strictly left-to-right with a tiny memory, self-attention lets the model build a rich map of relationships across the context window: grammar, references, meaning, dependencies, and patterns.

# MASKED SELF ATTENTION

When predicting the next word, the model is only allowed to look at words before it, not words after it.

For example -

    The cat sat on the ___

To predict the blank, the model can look at:

    The cat sat on the

But it cannot look at the answer if the full sentence is:

    The cat sat on the mat

Because if it could already see “mat,” the task would be cheating.

Now imagine the model is training on this full sentence:

    The cat sat on the mat

For each word, it predicts the next word:

    The        -> cat
    The cat    -> sat
    The cat sat -> on
    The cat sat on -> the
    The cat sat on the -> mat

Masked self-attention enforces that rule. At the position for sat, the model can attend to:

    The cat sat

But it cannot attend to:

    on the mat

The “mask” is like a curtain over future tokens.

Without the mask, during training the model could look ahead. That would make training easy but useless, because in real generation the future words do not exist yet.

It is also worth mentioning that since each token is compared to very other token in self-attention, the computation grows roughly as O(n^2) where 'n' is the number of tokens.

This is why large context windows are costly and scaling is challenging.

To summarize in self-attention -

    Every word in a sentence “looks around” and decides which other words matter most before forming its meaning.
