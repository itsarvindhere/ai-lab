Let's also have a high-level view of how LLMs are trained.

At a high-level, LLM training is the process of teaching a model to predict text by adjusting its parameters.

There is a loop that does all this -

    1. Give the model some text
    2. Hide the next token
    3. Ask the model to predict it
    4. Compare prediction with the real next token
    5. Measure the error
    6. Adjust parameters slightly
    7. Repeat many, many times

For example -

    Input:  The cat sat on the
    Target: mat

The model outputs the probabilities -

    mat     0.30
    floor   0.20
    chair   0.10
    pizza   0.01

If the correct next token is 'mat', the model is rewarded for increasing mat’s probability and reducing wrong choices.

Training starts with mostly random parameters, so early predictions are terrible. Over time, after seeing huge amounts of text, the parameters shift toward patterns that help prediction.

So, a simplified training loop is -

    text -> tokens -> model prediction -> error/loss -> parameter update

Here, 'loss' is the number that says how wrong the model was.

For example, if the correct answer was 'mat' but the model predicted 'pizza', that is a high loss.

The model uses an algorithm called 'back propagation' to figure out which parameters contributed to the mistake. Then an optimizer makes tiny updates to those parameters.

So -

    - loss tells how wrong the model is
    - back propagation finds which parameters affected the error
    - optimizer updates those parameters

There are a few broad stages in LLM training.

## 1. PRE TRAINING

The model learns general language patterns from massive text datasets. It learns things like grammar, facts, styles, reasoning patterns, code patterns, and associations.

The task is to usually predict the next token. This is where the model's broad capability comes from.

## 2. SUPERVISED FINE TUNING (SFT)

After pre-training, the model may be trained on examples of helpful responses.

For example, if a user asks the model to explain gravity in simple terms, the model might respond -

    Gravity is the force that pulls objects toward each other...

So, this teaches the model to behave more like an assistant, not just continue random internet text. 

## 3. PREFERENCE / ALIGNMENT TRAINING

The model is shown different possible answers and learns which ones humans prefer.

For example -

    Answer A: clear, safe, useful
    Answer B: vague or unhelpful

The training process nudges the model toward answers people rate better.

So, to summarize -

    Pre-training = learn language and world patterns
    Fine-tuning = learn how to answer usefully
    Alignment = learn what kinds of answers people prefer

An LLM is not manually programmed with knowledge. It is trained by making predictions, measuring mistakes, and updating parameters until useful patterns are encoded in those parameters.
