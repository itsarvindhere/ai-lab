An LLM (Large Language Model) is a kind of machine learning model (specifically, within NLP or Natural Language Processing) which is trained to understand, generate, and manipulate human language at scale.

So, what does 'Large' mean here?

'Large' refers to two things - 

    1. Size of the Model - billions or trillions or parameters
    2. Training Data - The model is trained on a massive corpora of text (books, code, websites and more).

Most modern LLMs are based on the 'Transformer architecture'. At the core is the concept of -

    1. Self-attention - The model looks at the relationships between words in a sequence
    2. Token prediction - It predicts the next token given the previous tokens

Fundamentally, an LLM is a 'probability engine' over sequences of tokens. This means, if we give it an input like -

    "The capital of France is "

It computes probabilities like -

    Paris: 0.92
    London: 0.03
    Berlin: 0.02

And then, it picks the most likely continuation.

This is the reason why LLMs can answer questions, write code, translate languages and summarize text, as as a variation of next-token prediction.

# HOW LLMs ARE TRAINED?

There are basically two main stages -

    1. Pre-training - builds capability
    It teaches the model how language and knowledge behave.

    2. Fine-tuning and alignment - shape behavior
    They teach the model how to interact with humans.

## 1. PRE-TRAINING

The first real stage is pre-training, and this is where almost all of the model’s raw capability comes from.

Pre-training is the process of training an LLM to have a general understanding of language, including linguistic patterns, grammar, syntax etc.

This is massively computationally expensive and requires a massive amount of data.

The idea is deceptively simple: the model is shown a sequence of tokens and asked to predict what comes next. That’s it. No explicit grammar rules, no labeled data saying “this is a noun” or “this is correct English.” Just prediction.

At each step, it processes something like:

    “The capital of France is”

and tries to predict the next token. Initially it guesses randomly.

The correct answer (“Paris”) is compared to its guess, and the model computes an error. Then all its internal parameters are slightly adjusted to reduce that error.

This process: predict, compare, adjust—runs over billions or trillions of tokens.

Over time, something interesting happens. To get better at prediction, the model is forced to learn:

    - grammar (because syntax affects what comes next)
    - meaning (because context matters)
    - facts (because “France → Paris” appears consistently)
    - reasoning patterns (because structured text encodes logic)

No one explicitly programs these. They emerge because they help minimize prediction error.

By the end of pre-training, the model has become a general-purpose language engine. It can complete text, answer questions, and even write code—but it’s still rough. It doesn’t reliably follow instructions, and its behavior can be inconsistent or unsafe.

## 2. SUPERVISED FINE-TUNING

After pre-training, the model knows language, but it doesn’t yet behave like an assistant. That’s where supervised fine-tuning (SFT) comes in.

Here, the model is trained on curated examples where humans provide both:

    1. The input (prompt)
    2. An ideal output (response)

So instead of just predicting the next token blindly, the model now learns patterns like:

    - When a user asks a question → provide a clear, structured answer
    - When asked for code → return correct, formatted code
    - When asked to explain → simplify appropriately

This step reshapes the model from “autocomplete engine” into something closer to an instruction follower.

Technically, it’s still doing the same thing: predicting tokens. But now it’s doing so in a much more constrained and guided way.

### PREFERENCE ALIGNMENT

Even after fine-tuning, multiple responses to the same prompt may be possible. Some are better than others—clearer, safer, more useful.

This is where alignment comes in, often through methods like Reinforcement Learning with Human Feedback (RLHF).

Instead of just saying “this is the correct answer,” humans compare multiple outputs and indicate which one they prefer. For example:

    Response A: technically correct but confusing
    Response B: clear, structured, and helpful

    Humans pick B.

A separate model (called a reward model) learns these preferences. Then the main model is further trained to prefer outputs that humans would rank higher.

What this changes is subtle but critical:

    - tone becomes more natural
    - answers become more structured
    - harmful or irrelevant outputs are reduced
    - the model learns when not to answer

At this point, the model starts to feel like a “polished assistant” rather than a raw generator.

So, to summarize -

    - Pre-training → the model learns to think in language
    - Fine-tuning → the model learns to respond to instructions
    - Alignment → the model learns to respond appropriately
