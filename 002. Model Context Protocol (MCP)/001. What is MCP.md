In the previous section, we learnt all about the basics of LLMs. But, the thing with LLMs is that their knowledge is frozen at the time of their training and by themselves, they cannot interact with the outer world.

So, by themselves, they cannot access any real-time data or perform actions like editing a file or writing a mail or adding comments on a PR etc.

Well, there is an open standard that was designed to solve this problem and it is the 'Model Context Protocol' or the 'MCP'. This was open-sourced by Anthropic in November 2024 and it provides a universal standard to connect AI systems with data sources.

MCP is like the USB-C port for AI applications. Just like a USB-C port provides a standardized way to connect electronic devices, MCP provides a standardized way too connect AI applications to external systems.

So, instead of every AI app needing a custom connection to things like Google Drive, Slack, Databases, GitHub etc, MCP gives them one common way to connect.

Without MCP -

    AI app needs custom GitHub integration
    AI app needs custom database integration
    AI app needs custom Slack integration
    AI app needs custom file integration

With MCP -

    GitHub exposes an MCP server
    Database exposes an MCP server
    Slack exposes an MCP server
    
    The AI app talks to all of them through MCP

So, when you ask -

    "Check my database and summarize the latest orders"

The AI does not magically know your database. An MCP Server can safely expose database tools or resources and the AI client can call them.

So, why does it matter?

For developers, it reduces development time and complexity when building or integrating with an AI application or agent. For end-users MCP results in more capable AI application that can access your data and take actions on your behalf when necessary.
